# 771 Toolbox（柒柒壹工具箱）

**五合一的 Windows 小工具合集，只有一个 exe，双击即用**——不用装 Python、也不用装任何依赖：
**格式转换 / 批量改名 / 视频下载 / 压缩解压 / 截图** 五个标签页，外加一页 **系统工具**
（文件哈希 / 重复文件 / 二维码 / 剪贴板历史）。内置 ffmpeg，转码、音视频加工、录屏开箱即用。
注:该软件为100%AI

当前版本：**v1.42**（2026-10-16）· Windows 10 / 11（64 位）

**从 v1.1 起带联网自动更新**：启动后会在后台查一次新版本（失败静默），发现新版才弹窗问你要不要更新，
下载后自动校验（Ed25519 签名 + SHA-256）再替换并重启。也可以手动到 Releases 下载。

## 六个标签页

### 格式转换

- **文档**：docx / pdf / txt / md / html 等互转（docx、pypdf、reportlab）。
- **图片**：jpg / png / webp / bmp / tiff / gif / ico / avif 等互转；「图片工具」页做批量压缩（按质量，或按**目标体积上限**）、改尺寸、加水印；还能**多图 → 一个 PDF**（纸型、白边）、**拼接**（横 / 竖 / 网格），以及按 EXIF 摆正、旋转翻转、加边框圆角。
- **音视频**：内置 ffmpeg（essentials 构建）负责转码与音轨提取（mp3 / mp2 / aac / wav / flac 等）；「音视频加工」页可从一段素材里**提取音频 / 换容器 / 按体积压缩 / 裁剪时间段 / 拼接多段**，也能**视频→GIF、抽帧与提取封面（可选 4×4 九宫格缩略图）**。
- **数据配置**：json / yaml / csv / xlsx 等互转。
- **PDF 工具**：合并 / 拆分 / 提取页、**页整理**（旋转 / 删除 / 重排）与**元数据**（标题 / 作者 / 主题），以及 **加密 / 解密**（AES-256 / AES-128 / RC4）与**加水印**（文字或图片，九宫位置、不透明度、字号、旋转）。
- **加密音乐解密**（只在本地解密、全程不联网）：网易云 `.ncm`、酷狗 `.kgm/.kgma/.vpr`、QQ 音乐 `.qmc*/.mflac/.mgg`（自带密钥的版本）。

### 批量改名

正则替换、加前后缀、序号编号；也能按**拍摄时间**改名（读 EXIF 的 36867 / 36868，退到 306）。

### 视频下载

基于 yt-dlp，支持它认得的一千多个站点；可选画质（1080p / 720p / 480p / 最高画质，或**仅音频直出 mp3**）、
可**同时下载字幕**（含自动字幕与语言选择）、非 H.264 时能顺手转成通用 MP4；
另有「**直链下载**」入口——抖音那类"站内页下不动"的情况，把解析出来的 `.../xxx.mp4` 粘进去就能下
（下回来要是个网页会**明确报错并删掉垃圾**，不假装成功）；还能一键取 **B 站封面**。

### 压缩解压

zip / 7z / rar 等解压，支持**拖入即解压**（解到同名文件夹）；**rar 用内置的 7z 组件直接解**
（v1.42 起，机器没装 7-Zip / WinRAR 也能全离线解；带密码的包在「压缩」页密码框填密码）；
压缩可选 **7z AES-256 加密**。

### 截图（与独立版同源）

- **区域截图 + 就地标注**：拖完范围，工具栏直接出现在选区旁——矩形 / 椭圆 / 箭头 / 铅笔 / 文字 / 马赛克 / **模糊** / 高亮 / 序号（九种，马赛克块大小与模糊强度随线宽调），五色可选、线宽可调，带撤销 / 重做 / 清空；`Enter` 保存并复制、`Ctrl+S` 只保存、`Esc` 取消。
- **窗口截图**：悬停高亮窗口边框，点一下截那个窗口；产物是窗口自己的内容，不会被别的窗口挡住。
- **滚动长图**：框选可滚动区域后自动逐帧拼成长图（失败不留半成品）。
- **取色器 / 屏幕标尺**：放大镜取色（HEX / RGB，点一下复制）；拖框量宽高并显示刻度。
- **贴图**：把截图钉在桌面上，可拖动、拖任意边或角改大小、`Ctrl+滚轮` 调透明度。
- **屏幕录制（只出 GIF）**：按一下开始录、再按一下停止；可设录整屏或录区域、帧率、时长上限、GIF 宽度，录制期间屏幕上有个小红条显示时长并带「停止」「取消」。**GIF 没有音轨，所以本版没有录音设置。**

### 系统工具

- **文件哈希**：sha256 / md5 / sha1 / crc32；流式读、不占内存；可导出 coreutils 风格的清单，也能拿一份 `.sha256` / `.md5` 来核对（**certutil 的输出也认**），逐条给出通过 / 不通过 / 跳过与原因。
- **重复文件**：大小 → 前 4KB → 全量哈希三级筛；**默认只报告、绝不自动删**，清理走回收站（误删可还原）。
- **二维码**：生成（带 UTF-8 的 ECI 声明，中文不乱码；不用很多软件读不了的 Micro QR）与识别（选图片，或直接读**剪贴板里的图**）。
- **剪贴板历史**：**默认不记录**，勾上「开始记录」才读，且**这个选择会被记住**；默认只在内存，可选重启保留；支持**自由复制**——点一条看全文，拖选其中一段只把那段放进剪贴板。
- **文件切割与合并**：大文件切成 `原名.partNN`（按每块 MB / 按份数），选任意一片按序号拼回（缺号明确报错、不留半成品）。
- **大文件与空文件夹**：目录下最大的 N 个文件（双击打开所在文件夹）／真空目录扫描（只删真正一条条目都没有的，回收站可还原）。
- **文本小工具**：Base64 / URL 编解码、随机密码生成（secrets）、正则测试（含捕获组）。
- **图片取字（离线）**：Windows 自带 OCR 引擎取字，全程不联网；截图预览区也有「取字」。

## 快捷键（默认值，可在界面里改）

| 功能 | 默认键 |
| --- | --- |
| 区域截图（拖选后就地标注） | `Ctrl+Alt+A` |
| 全屏截图 | `Ctrl+Alt+S` |
| 窗口截图 | `Ctrl+Alt+W` |
| 取色器 | `Ctrl+Shift+C` |
| 屏幕标尺 | `Ctrl+Shift+M` |
| 标注最近一张 | `Ctrl+Alt+N` |
| 贴图工具窗 | `Ctrl+Shift+P` |
| 屏幕录制 | `Ctrl+Shift+R` |
| 区域录制 | `Ctrl+Shift+Alt+R` |

> 「全屏截图」默认**不给裸键**（比如 `Home`）：裸键在遮罩出现之后会失灵。想改成裸键也行，界面里会提醒。

## 配置与日志在哪

- 配置：`%APPDATA%\柒柒壹工具箱\`（`config.json`、截图 `screenshot_cfg.json`、系统工具 `systools_cfg.json`）
- 更新日志：同目录 `update_log.txt`；想换加速镜像可在 `update_mirrors.txt` 里按 `前缀` 或 `url=完整清单地址` 写一行
- 截图默认保存目录可在界面里改，文件名为 `shot_年月日_时分秒.png`；录制产物是 `rec_年月日_时分秒.gif`
