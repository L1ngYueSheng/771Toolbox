# 771 Toolbox（柒柒壹工具箱）

**Windows 桌面工具箱**：格式转换 / 批量改名 / 视频下载 / 压缩解压 / 截图，外加 **30 个子页的系统工具**（文件管理 / 系统维护 / 文本开发 / 窗口置顶 / 右键菜单 / 局域网快传 / 网络诊断 / GIF 工具等）。
一个窗口里把常用小工具做完；除视频下载与联网更新外全部离线可用。注:该软件为100%AI

当前版本：**v2.0.38**（2026-10-24）· Windows 10 / 11（64 位）

> **v2.0 起软件换成 Flutter 新版外壳**——同一套工具、同一个安装位置、同样的保存目录与热键习惯。
> 旧版 v1.45（tkinter 外壳）仍在历史 Release 可下载。

**带联网自动更新（v2.0.1 起）**：启动后后台查新（失败静默），发现新版弹窗询问。
下载默认走国内镜像（`ghfast.top` → `gh-proxy.com` → `ghproxy.net` → GitHub 直连兜底），
开跑 6 秒低于 60KB/s 自动换线路并记住可用线路；清单 Ed25519 验签 + 载荷 SHA-256/体积双校验，
镜像返回内容不符也会自动换线。

## 功能

- **界面与主题（v2.0.33）**：浅色 / 深色 / 跟随系统；点状态栏「主题」时，新主题从被点控件中心向外扩张成水滴涟漪（400 ms），圆边缘带一条淡出的高光细环；不再出现整窗弥散渐变。
- **窗口置顶 / 透明度（v2.0.34 新增）**：系统工具 →「窗口置顶」，列表或准星选一个窗口，置顶 / 30%–100% 透明度 / 一键还原；每次操作后回读 exstyle 与实际 alpha 显示在页面上，只影响选中的那一个窗口。
- **资源管理器右键菜单（v2.0.34 新增）**：系统工具 →「右键菜单」一键安装（只写 HKCU：文件 / 文件夹 / 目录空白），右键「用柒柒壹工具箱打开」→ 工具箱跳到文件搜索页并定位；exe 移动后页面标红旧路径、可「重新注册」；卸载回读全无。
- **右键文件转换格式（v2.0.35 新增）**：右键**任意文件**选「用柒柒壹工具箱转换格式」→ 工具箱切到格式转换页，按扩展名自动识别类别（文档 / 图片 / 数据 / 配置 / 音视频 / 字幕 / 加密音乐）并预选一个与源不同的目标格式；确认后点「开始转换」。只登记文件项；多选 3 秒内合并成清单（当前页一次转一个）。
- **截图蒙层修复（v2.0.36）**：区域截图 / 取色 / 标尺的蒙层期间暂停窗口边缘缩放热区；鼠标移到屏幕四边或四角保持十字，框选不会被打断；退出蒙层后窗口边缘缩放恢复。
- **滚动截图遮罩（v2.0.37）**：框选阶段选中区域提亮并带亮蓝边框，未选区为灰色；真正滚动时保留灰色遮罩，选区内透明显示实时页面，控制条浮在遮罩上；结果图不含遮罩/边框。
- **局域网快传（v2.0.38）**：系统工具 →「局域网快传」，手机连同一 WiFi 扫码打开网页，上传/下载文件；流式写盘、随机令牌（错令牌 403）、文件名清洗防穿越；停止即释放端口。
- **网络诊断（v2.0.38）**：系统工具 →「网络诊断」，本机网卡/网关/DNS、Ping、路由跟踪、DNS 查询、端口连通（开放 / 拒绝 / 超时）；全程免管理员、不改防火墙。
- **GIF 工具（v2.0.38）**：系统工具 →「GIF 工具」，图片/视频合成 GIF（两遍 palettegen → paletteuse）、拆帧为 PNG、调速、三档/目标体积压体积；纯 Dart 调速不依赖 ffmpeg 的 PTS。

### 格式转换
- 文档：md / html / txt / csv / docx / rtf 互转
- 图片 34 种：jpg / png / webp / bmp / gif / tiff / ico / tga / qoi / jp2 / ppm / pcx / sgi / xbm，
  以及 EXR / HDR / DPX / FITS / PAM / PBM / PGM / PFM / PHM / PGMYUV / WBMP / XWD /
  Sun Raster / JPEG-LS / ljpeg / Alias PIX / XFace；AVIF / APNG / 动图 WebP
- 数据：json / yaml / csv / xml / toml / properties / yml 互转；配置：json / env / ini 互转
- PDF：图片 → 单页 PDF；图片工具：按宽度等比缩放
- 音视频 42 种源格式 + 专业/怀旧目标：mp3 / flac / ogg / opus / aac / wma / m4a / wav / mp4 / mkv / avi / webm / 3gp 等；
  H.265 / AV1 / ProRes / FFV1 / HLS 切片 / DVD VOB / AMR-WB，以及 SWF / RM / WTV / IVF / VCD / SVCD / SMJPEG /
  Huffyuv / Ut Video / MagicYUV 等；同容器优先快封（`-c copy`），失败自动回退重编码；目标重名自动加序号
- 字幕：srt / ass / ssa / vtt 互转；字幕以 mov_text 字幕轨嵌入 MP4
- 图像序列：视频导出 PNG / JPG 序列；图片序列合成视频（序号断档会明确报错）
- 滚动截图：拖框后按 Enter 开始滚动，点控制条「完成」或按 Esc 可随时停下并保存当前长图
- 加密音乐解密：ncm / kgm / kgma / vpr / qmc0·qmc3·qmcflac·qmcogg / mflac / mgg

### 批量改名 / 视频下载 / 压缩解压
- **批量改名**：批量替换、前后缀、序号等规则
- **视频下载**：自带 yt-dlp（`程序\引擎\yt-dlp.exe`）+ 直链下载 + B 站封面
- **抖音视频 / 图文（v2.0.32 新增）**：粘贴分享文案 / 短链 / 长链即可；视频默认优先 **H.264**（Windows 自带播放器直接可放），源没有 H.264 时自动转码；图文自动下载全部图片并转 JPG（存到 `标题_作者_图文\01.jpg…`）；大文件断流自动 Range 续传、可取消；需要人机验证时弹窗完成后自动继续
- **压缩解压**：zip（流式）/ 7z / rar（自带 `程序\引擎\7z\7z.exe`）；**分卷压缩**（v2.0.31 新增）可设分卷大小（MB），zip / 7z 都支持，产物为 `.001`、`.002`…；解压时选 `.001` 即可（7z 自动读取其余分卷），重压前自动清理同名旧分卷

### 文件管理增强（v2.0.29 新增）
- **文件搜索**：文件名通配符、内容关键字（文本类，UTF-8 / GBK）、大小区间、含子目录开关；可导出 CSV
- **文件夹对比同步**：镜像 / 单向增量 / 双向合并；先出差异再执行，删除只进 `.trash_时间戳`（回收区不参与下次对比）
- **相似图片**：pHash 归组，缩放 / 压缩 / 改亮度仍能识别；可一键把每组其余项移入回收区
- **文件加密**：AES-256-CBC + HMAC-SHA256（PBKDF2 10 万次），口令错或密文被改会明确失败
- **哈希清单**：生成 / 校验 SHA-256 清单，兼容 `sha256sum` 的 `./` 前缀与 CRLF
- **批量改名升级**：正则捕获组、序号步长、日期变量；撞名 / 非法字符 / Windows 保留名一律拦截

## 拖放
格式转换页、压缩解压页、批量改名页都支持把文件 / 文件夹**直接拖进窗口**：
- 格式转换页：拖入自动填源，并按扩展名自动切好类别；
- 压缩解压页：解压模式下把压缩包拖进来 = 立即解压；
- 批量改名页：拖入文件夹即填目标目录（拖文件取其所在目录）。

## 引擎（自带，免安装）
`程序\引擎\` 内含 `yt-dlp.exe` / `ffmpeg.exe` / `7z\7z.exe`；取字用 Windows 自带离线 OCR。
许可全文见包内 `第三方来源与许可证.txt`。

## 全局热键（默认键位；都可以在「截图」页点按键修改）
- `Ctrl+Alt+A` 区域截图（就地蒙层：拖框 / Enter 确认 / Esc 取消）
- `Ctrl+Alt+5` 全屏截图 · `Ctrl+Alt+6` 取色器 · `Ctrl+Alt+7` 贴图最近一张 · `Ctrl+Alt+G` 滚动截图
- 旧版截图工具同时在跑时，被占的键会如实显示“被占用”并让位。
